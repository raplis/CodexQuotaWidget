Codex 额度浮窗 - 免安装版

使用方法：
1. 将整个文件夹解压到任意位置。
2. 双击 CodexQuotaWidget.exe 启动。
3. 如果提示未找到登录状态，请先在本机登录 Codex CLI。

系统要求：
- Windows 10/11 64 位
- 需要安装 .NET 8 Desktop Runtime（Windows Desktop Runtime）。
- 当前版本是免安装文件夹版，但不是自包含版本。

安全说明：
- 本便携包不包含任何账号、Token 或 auth.json。
- 每台电脑都会读取该电脑自己的：%USERPROFILE%\.codex\auth.json
- 不要把自己的 auth.json 复制给别人。

卸载方法：
直接删除这个文件夹即可。程序设置保存在当前用户的 %APPDATA%\CodexQuotaWidget 中，
如需清除设置，请同时删除该目录。
